# Defects that reviews have already caught

Check every shot against this table before you snapshot.

| Defect | Rule that prevents it |
| --- | --- |
| Characters obscured by props, or nameplates blocked | Measure the bounds, put the feet on the support, faces to the lens, plates at the front |
| Weak speaker shots, a cropped booth, a desk clashing with the subject | Drive cuts and pushes from the speaking row. Check the face, the eyes and caption clearance at the row's timestamps. |
| Agents hard to tell apart, faces dark | Use exact agent accents with a neutral shell and coloured glow. Light with a warm key, a cool rim and a fill. |
| Text overlays colliding with each other | Lock typography at native size. Keep stamps and cards in the margins and check them over the 3D. |
| Wrong character, or clip-driven animation that is not seek-stable | Use the cute robot GLB, a morph only for the blink, and sampled rigid acting |
| `window.__timelines` undefined | Initialise it before each assignment |
| Missing model credit | Put author, licence and changes in `CREDITS.md` and on the end card |
| A stamp crossing a face or a key word | Time the stamp's travel to avoid faces, lift it clear, and check the transition frames |
| A prop reading as the wrong object | Orient it so its silhouette reads from the camera, and frame its label head-on |
| A subject facing away, cropped at the edge, or with an accessory clipping through | Check the shot edges and a face close-up at the final camera |
| Primitive god or hero figure | Use a sourced GLB (see `models.md`) |
| A promised spark or bolt missing or tiny | Build it to the effect recipe in `look-recipes.md` and check it at phone size |
| An empty wide desert or exterior | Fill the layers named in the brief (crews, ramps, banners, blocks) and keep the action at 15% or more of the frame |
| A sofa or character floating | Ground it to measured bounds and add a contact shadow |
| A blank last frame in a scene | Snapshot `start + duration - 0.1` and keep the set mounted until the scene's end |

# Episode 5 — Same Me

**The one message (end card):** Same agents. Different house rules.

**Logline:** The same bug lands in two homes at once. Codex takes the job in
both — relaxed in T3 Code's loft, under the gavel in Ptah's temple — and the two
Codexes finally meet at the split line.

**Audience:** T3 Code's audience and anyone choosing a multi-agent tool. This is
the friendly bridge episode: both homes look good, both finish the job.

**Want and obstacle:** each Codex wants to ship. Left, the person picks the agent
and checks the diff. Right, the temple picks the agent and a different-family
reviewer checks. Neither is the villain; the joke is the same agent living two
lives.

**Length and format:** 45–55 s. A split screen: left/right in 16:9, top/bottom
in 4:5 (T3 Code on top, Ptah below). Both cuts matter here; 4:5 is still the feed
default.
